# Fused Productions - Site Architecture & Page List

## Overview
The Fused Productions website serves as the primary marketing funnel and gateway to our proprietary client and vendor portals. The core value proposition is **single-point-of-contact event management**, eliminating multi-vendor chaos.

## Core Page List
1. **Home (`/`)**
   - Hero Section: High-impact video loop of past events, clear value proposition ("All-in-One Event Production & Management").
   - Service Overview: Summary of venue setup, culinary/bar operations, production/entertainment, and design/decor.
   - Trust Indicators: Fixed pricing, single contract guarantee, transparency messaging.
2. **Services (`/services`)**
   - Detailed breakdown of tiered event packages and custom scoping.
   - Explanation of how Fused Productions acts as the sole general contractor[cite: 1].
3. **Client Portal (`/portal/client`)**
   - Secure login gateway for active clients.
   - Access to master dashboard, countdowns, milestones, document execution, and payment ledgers[cite: 1].
4. **Vendor Portal (`/portal/vendor`)**
   - Secure onboarding and schedule dispatch board for subcontractors[cite: 1].
   - COI and SLA uploads, run-sheet sync.
5. **About (`/about`)**
   - Company background, mission, and operational philosophy.
6. **Contact (`/contact`)**
   - Inquiry form for prospective corporate, wedding, and municipal clients.
