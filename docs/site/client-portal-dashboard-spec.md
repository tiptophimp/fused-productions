# FUSED PRODUCTIONS - CLIENT PORTAL DASHBOARD SPECIFICATION

## 1. Core Purpose

The client portal acts as the single source of truth, offering total visibility and eliminating communication friction between the client and Fused Productions.

## 2. Key UI/UX Modules

- **Live Countdown & Status Widget:** Real-time countdown clock to the event date and current project phase indicator (e.g., Design Approval, Production, Execution).
- **Interactive Milestone & Timeline Tracker:** Visual progress bar tracking completed phases mapped to an interactive master run-sheet.
- **Financial & Billing Ledger:** Secure table displaying milestone payment statuses (30% retainer, 40% planning draw, 30% final settlement) with integrated payment execution buttons.
- **Document Vault:** Secure file repository for executing digital signatures on Master Service Agreements, venue permits, and layout addendums.
