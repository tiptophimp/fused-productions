# FUSED PRODUCTIONS - VENDOR PORTAL DISPATCH BOARD SPECIFICATION

## 1. Core Purpose

Manages all external partners, crew assignments, and sub-vendors behind a secure, role-based operational interface.

## 2. Key UI/UX Modules

- **Compliance Management Hub:** Status dashboard tracking verified W-9 forms and active Certificates of Insurance (COI) naming Fused Productions as an additional insured.
- **Gig Dispatch Board:** Calendar and list view displaying assigned upcoming events, load-in zone maps, and strict arrival windows.
- **Synchronized Run-Sheets:** Real-time mobile-optimized view of cue-to-cue schedules and sound checks, ensuring all sub-vendors operate on identical timing.
- **Invoice & Payout Tracker:** Interface for submitting job completion sign-offs and tracking milestone payouts synchronized with client draw releases.
