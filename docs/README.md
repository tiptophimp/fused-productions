# Drop files here

This folder is **not** on the live website. Files you put here stay in the project on disk. Only `public\` is what visitors can download.

| Put this | Folder |
|---|---|
| Site map, page list, “how the site should work” | `docs\site\` |
| Layout / wireframes / page framework | `docs\design\framework\` |
| Logos, wordmarks, favicon source | `docs\design\logos\` |
| Concept art, mockups, mood boards | `docs\design\concepts\` |
| Photos/video you might use later (small files) | `docs\media\` |
| Big camera dumps, long videos | `docs\media\inbox\` (not uploaded to GitHub) |
| Blank **customer** agreements (DJ, catering, planning) | `docs\contracts\customers\` |
| Blank **vendor** agreements | `docs\contracts\vendors\` |
| Signed / filled-in contracts with real names | `docs\contracts\signed\` (stays on this PC only) |

**Live site pictures** (already on fusedproductions.com after deploy) go in:

`E:\Dev\fused_productions\public\images\`

Do not drop working files in `src\` or `public\` unless you intend the public to see them.
