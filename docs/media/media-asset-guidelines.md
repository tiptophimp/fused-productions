# Fused Productions - Media Asset Guidelines

## Purpose
Storage for approved, edited, and raw archival photos from past events used for portfolio building, social media, and client case studies.

## Naming Convention
`[YYYY-MM-DD]_[Event-Type]_[Location]_[Asset-ID].[ext]`
*Example:* `2026-06-14_CorporateGala_ClevelandConventionCenter_01.jpg`
