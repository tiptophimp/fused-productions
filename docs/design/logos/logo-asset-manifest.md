# Fused Productions - Logo Asset Manifest

## Asset Directory Rules
Place all raw and exported logo files in this directory (`docs\design\logos\`) using the following naming convention:
- `fused-productions-logo-primary-[format].[ext]`
- `fused-productions-logo-monochrome-[format].[ext]`
- `fused-productions-mark-only-[format].[ext]`

## Approved File Formats
- **Vector (Master):** `.ai`, `.svg`, `.eps` (Required for print, banners, and stage backdrops)
- **Raster (Digital):** High-res `.png` with transparent backgrounds (Minimum 2400px width for web and portal headers)
