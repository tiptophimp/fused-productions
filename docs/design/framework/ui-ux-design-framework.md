# Fused Productions - Design Framework & UI/UX Standards

## Brand Aesthetic
- **Tone:** Professional, high-end, structured, transparent, and modern.
- **Color Palette:** High-contrast dark backgrounds with clean metallic accents (gold/bronze) and sharp white typography for maximum legibility on dashboards.
- **Typography:** Clean sans-serif primary font (Inter / Roboto) optimized for data-dense client portals and financial tracking tables.

## Layout Standards
- **Grid System:** 12-column responsive grid framework.
- **Mobile-First Design:** Critical for day-of operations, crew dispatch boards, and client portal access on smartphones.
- **Component Consistency:** Reusable card components for milestone tracking, payment status badges, and collapsible accordions for technical riders.
