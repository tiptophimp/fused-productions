# Fused Productions

**Turnkey event services: DJ, laser light shows, and catering.**

One team. Every service. Unforgettable events.

## Services

- **DJ Services** - Professional DJs with extensive music libraries, state-of-the-art sound systems
- **Laser Light Shows** - Stunning visual experiences with cutting-edge laser technology
- **Catering** - Exceptional culinary experiences from elegant dinners to casual buffets

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide Icons

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Deployment

Production runs on GMKtec via Nginx Proxy Manager with Let's Encrypt SSL.

Domain: [fusedproductions.com](https://fusedproductions.com)
